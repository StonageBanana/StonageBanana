### Featured Projects

</div>

**Markerless vs. Marker-Based Motion Capture — SAM 3D Body vs. Vicon** *(2026)*
Tested whether a two-camera markerless setup can substitute for a 10-camera Vicon rig in clinical gait analysis. Root-caused a systematic geometric distortion present in every trial — hip keypoints compressed to ~44% of true width, pelvis axis ~106° misaligned — cutting hip and knee flexion RMSE by **66–75%** (knee: 84° → 21°) and flipping correlation with ground truth from strongly negative to strongly positive. Nine-stage reproducible pipeline with a regression-audit suite enforcing mathematical invariants; two-view fusion requiring **zero camera calibration**.

**Custom CNN Architectures for Histopathological Cancer Classification** *(2024)*
Three architectures benchmarked on the 25,000-image LC25000 dataset — from-scratch baseline, Custom ResNet with attention + ImageNet transfer, Custom EfficientNet with compound scaling. **97.2% accuracy** with EfficientNet, plus Grad-CAM heatmaps so predictions are reviewable by a pathologist.

**Pathfinding: Classical Search vs. RL vs. Sampling Planners** *(2025)*
Twelve planners across three algorithmic families behind a single abstract base class — A\*, Dijkstra, JPS, Q-Learning, SARSA, DQN, RRT, RRT\*. **DQN built from scratch in PyTorch** (replay buffer, target network, ε-greedy decay, Bellman loss). Real-time Pygame visualization makes on-policy vs. off-policy divergence directly observable.

**Flight Price Prediction — Deployed ML Web Application** *(2023)*
Eight regression algorithms compared on 10,000+ records; **CatBoost at ~96% R²**, chosen because ordered target statistics handle high-cardinality categoricals natively. [**Try it live →**](https://stonagebanana-flight-price-prediction-smartb.hf.space/)
